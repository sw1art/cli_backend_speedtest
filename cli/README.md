# Download Benchmark CLI

Консольная утилита на Python для замера скорости скачивания. Выполняет
заданное число **последовательных** HTTP GET-запросов к одному URL, полностью
дожидается тела каждого ответа и выводит среднее время запроса, общий объём
скачанных данных и среднюю скорость загрузки.

## Требования к окружению

- Python 3.10 или новее
- Доступ в интернет до целевого ресурса (или до локального сервера)

## Установка

Создайте виртуальное окружение и установите зависимости:

```bash
cd cli
python -m venv .venv

# Linux / macOS
source .venv/bin/activate
# Windows (PowerShell)
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Утилиту можно запускать двумя способами:

```bash
# 1) как модуль (без установки пакета)
python -m download_benchmark <URL>

# 2) после установки пакета — отдельной командой
pip install -e .
download-benchmark <URL>
```

## Запуск

```bash
python -m download_benchmark https://example.com/image.jpg
```

### Параметры командной строки

| Аргумент | Описание | По умолчанию |
|----------|----------|--------------|
| `url` | Обязательный позиционный аргумент — целевой адрес | — |
| `-n, --requests` | Количество последовательных запросов | `10` |
| `-t, --timeout` | Таймаут одного запроса, секунды | `30.0` |
| `--json` | Вывести результат одним JSON-документом вместо таблицы | выключено |
| `--version` | Показать версию | — |

### Пример вывода

```
========== DOWNLOAD BENCHMARK ==========

URL: https://example.com/image.jpg
Requests: 10

Request 1: 1.24 sec | 2.50 MB
Request 2: 1.18 sec | 2.50 MB
Request 3: 1.31 sec | 2.50 MB
...

----------------------------------------
Average request time: 1.25 sec
Total downloaded: 25.00 MB
Average speed: 2.00 MB/s
========================================
```

## Единицы измерения

Все величины считаются в **десятичных (SI) единицах**:

- объём данных: `B`, `KB`, `MB`, `GB`, где `1 KB = 1000 B`, `1 MB = 1000 KB`;
- время: секунды (`sec`);
- **скорость скачивания: `MB/s`** (мегабайт в секунду), где
  `1 MB/s = 1 000 000 байт/с`.

Скорость рассчитывается как `общий объём успешных загрузок / суммарное время
успешных запросов`. Среднее время — среднее арифметическое по успешным
запросам. Запросы, завершившиеся ошибкой (нет соединения, таймаут, HTTP 4xx/5xx),
показываются отдельно и **не участвуют** в итоговых величинах.

## Обработка ошибок

- некорректный URL (не `http(s)`, без хоста) — сообщение об ошибке, код выхода `2`;
- ошибки соединения, таймауты и HTTP-ошибки — фиксируются по каждому запросу
  и не прерывают остальные запросы;
- прерывание `Ctrl+C` — печатаются накопленные к этому моменту результаты;
- если **ни один** запрос не завершился успешно — код выхода `3`.

Коды выхода: `0` — успех, `2` — ошибка использования, `3` — нет успешных запросов.

## Примеры

```bash
# 10 запросов к картинке (значение по умолчанию)
python -m download_benchmark https://httpbin.org/image/jpeg

# 20 запросов с таймаутом 5 секунд
python -m download_benchmark -n 20 -t 5 https://example.com/large.bin

# Машиночитаемый JSON
python -m download_benchmark --json https://example.com/image.jpg
```
